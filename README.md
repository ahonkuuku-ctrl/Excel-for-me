# 📊 Excel Explorers — Teaching Kids Spreadsheets

An interactive, browser-based game that teaches young children (ages 6–10) the very basics of spreadsheets and Excel-style formulas — through clicking, playing, and earning stars.

## 🎯 What Is This?

**Excel Explorers** is a single-page web app that looks and feels like a mini spreadsheet. Kids learn by doing:

- 🖱️ **Click cells** to select them
- 🔍 **Discover formulas** hidden inside cells
- ✏️ **Type their own formula** (`=A2+B2`) and watch it calculate
- ⭐ **Earn stars** for completing simple tasks

No installation. No login. Just open and play.

---

## ✨ Features

| Feature | Description |
|---|---|
| **Interactive Grid** | A 5×3 spreadsheet (columns A–E, rows 1–3) that responds to clicks |
| **Formula Bar** | Shows the selected cell's reference (e.g., `A1`) and its contents |
| **Live Formula Evaluation** | Formulas like `=A1+B1` are calculated instantly |
| **Guided Tasks** | Three progressive challenges with visual hints |
| **Star Rewards** | Kids collect up to 3 stars as they complete tasks |
| **Double-Click to Edit** | Kids can type their own values or formulas |
| **Reset Button** | Start the whole game over with one click |
| **Kid-Friendly Design** | Big buttons, playful fonts, bright colors, emoji feedback |

---

## 🎮 How to Play

1. **Task 1 — Discover a formula:** Click cell **C1**. It looks like a number, but it's actually a formula!
2. **Task 2 — Explore values:** Click **A2** and **B2** to see the numbers that will be used in a sum.
3. **Task 3 — Write a formula:** Double-click **C2**, type `=A2+B2`, and press Enter.

Complete all three to become a certified **Excel Explorer** 🏆
